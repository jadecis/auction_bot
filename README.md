# Telegram-бот аукциона

Экспериментальный бот с игровым сценарием, учётом баланса, обработчиками пополнения и вывода и фоновыми уведомлениями.

**Стек:** aiogram 2, SQLite, YooMoney.

## Устройство проекта

- `bot_polling.py` — точка входа.
- `loader.py` — создание клиентов и общих зависимостей.
- `src/handlers/` — Сценарии диалогов.
- `src/keyboards/` — Клавиатуры.
- `src/database/` — Доступ к данным.
- `src/commands/` — Команды.

## Локальная настройка

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Проверьте `config.py` и параметры, импортируемые в `loader.py`: задайте собственный токен бота, административные ID и необходимые подключения. Храните рабочие секреты вне Git. Если проект использует базу данных, подготовьте её схему и тестовые данные по слою доступа к данным; наличие файла базы в репозитории не означает готовность к эксплуатации.

После настройки зависимостей и конфигурации запускайте из корня репозитория:

```bash
python bot_polling.py
```

## Статус

Исходный проект для изучения асинхронных ботов и разделения обработчиков. Запуск внешних сервисов и production-готовность этой версии не подтверждены. Код рассчитан на API aiogram 2; обновление до aiogram 3 требует адаптации. Платёжные сценарии рассматриваются как экспериментальные; работа с реальными средствами не проверена.
